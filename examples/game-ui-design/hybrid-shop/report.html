1. Generated concept and precise hybrid layout

The image establishes the watercolor, ink and woodland character direction. The SVG keeps that illustration style but reduces the purchase action to 160 × 48 and places live text and controls explicitly. The portrait and two item illustrations were generated as separate assets; the item alphas were verified. The full concept is never used as a fake interactive screen.

2. Native Godot comparison

The direct builder saw the written brief and its own runtime captures. It did not see the generated concept, SVG mockup, other branch, or earlier demo designs. Both branches could inspect their running UI and fix defects.

3. Assessment

QuestionObservation
Does image generation add visual character?In this example, the fox, shop interior, glass and crystal have much richer material and drawing detail. The direct version is a viable simpler flat-art alternative.
Does that automatically improve layout?No. The initial image has larger, more decorative controls. The hybrid SVG deliberately tightens layout and control sizing. Both native versions have a clear purchase hierarchy.
Does the final UI preserve the generated concept?The hybrid carries the illustration, palette and type direction into Godot. It simplifies the painted parchment, ornate borders and flourishes. Full reproduction of those UI materials remains incomplete and is not claimed.
Did seeing the runtime help?Yes. The first hybrid capture had speckled image downscaling. Mipmapped filtering made the art smoother, though slightly softer than the browser SVG. Keyboard testing found and fixed a Tab trap when Buy became disabled. The final Buy button remains 160 × 48 at both sizes. The first runtime capture is preserved.
Is it still a real interface?Yes. Images supply illustration. Labels, wallet, prices, stock, item selection, focus and purchase behavior are native Controls in both branches.
What extra work did hybrid require?Four image calls: one full UI concept and three asset derivations. It also requires asset storage, alpha inspection, an SVG layout and engine comparison. This exercise does not establish a speed advantage.

When the routes apply

Use image concepts when art direction is unresolved or the screen needs painted frames, materials, portraits or illustrations. Use hybrid when those images need precise layout, editable labels and native interaction. An explicit request overrides the default SVG route.

Use $game-ui-design. Force the hybrid route: generate and inspect a visual concept, prepare separate artwork, refine the layout in SVG, then implement native UI and compare actual screenshots.
